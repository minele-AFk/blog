# 戏子多秋 の 小站 🚀

一个具有二次元风格的个人博客网站，用于记录技术学习、生活感悟和动漫推荐等内容。

## 技术栈

- **框架**: Next.js 16 + React 19
- **样式**: Tailwind CSS 4
- **动画**: Framer Motion
- **内容**: Markdown (gray-matter + remark)
- **认证**: JWT + bcrypt
- **部署**: Vercel / 自建服务器 (Next.js 动态应用)

## 功能特性

- ✨ 二次元风格 UI，毛玻璃卡片 + 霓虹边框
- 🔍 全文搜索功能（支持标题、内容、标签、分类）
- 🎵 完整音乐播放器（播放列表、切歌、进度控制、音量、收藏）
- 📝 Markdown 博客系统
- 🎨 粒子背景动画
- 📱 响应式设计（移动端菜单）
- 🌙 日间/夜间主题切换
- 📊 系统状态显示（运行时间、文章数等）
- 🔐 管理员后台管理（项目、说说、友链、图库）
- 🖱️ 拖拽排序功能
- ⬆️ 回到顶部按钮
- ✨ 页面过渡动画
- 🖼️ 背景图片自动轮换
- 🌸 追番记录（同步 Bangumi 收藏，支持在看/看过/想看/搁置/抛弃分类）
- 📤 图片上传（说说多图、项目封面，支持拖拽/本地选择/外链，JWT 鉴权 + 魔数校验 + 总量限制）
- 🗂️ 图库管理（统一查看/删除已上传图片）

## 快速开始

### 环境要求

- Node.js >= 20.0.0
- npm >= 10.0.0

### 安装与运行

```bash
# 安装依赖
npm install

# 创建环境变量文件
cp .env.example .env

# 启动开发服务器（端口 3000）
npm run dev

# 构建
npm run build

# 启动生产服务器
npm run start
```

## 环境变量配置

在项目根目录创建 `.env` 文件：

```env
# JWT 密钥（用于生成管理员认证令牌）
JWT_SECRET=your-secret-key-here

# 管理员密码（登录时使用）
ADMIN_PASSWORD=your-admin-password

# Bangumi API Token（用于同步追番数据）
BANGUMI_TOKEN=your-bangumi-token-here

# Cron Secret（用于定时同步认证，可选）
CRON_SECRET=your-cron-secret-here
```

> **注意**: 首次运行时系统会自动创建默认管理员账户，密码为 `ADMIN_PASSWORD` 的值。

## 管理员使用指南

### 登录方式

连续点击页面左上角的 Logo **4次**，会弹出管理员登录弹窗，输入密码即可登录。

### 管理功能

登录后可在以下页面直接进行管理操作：

| 页面 | 功能 |
|------|------|
| `/projects` | 添加、编辑、删除、拖拽排序项目（支持封面上传） |
| `/moments` | 添加、编辑、删除、拖拽排序说说（支持多图上传） |
| `/friends` | 添加、编辑、删除、拖拽排序友链 |
| `/admin/gallery` | 图库管理：查看/删除所有已上传图片 |

### 退出登录

点击导航栏右侧"管理"按钮内的红色退出图标即可退出。
