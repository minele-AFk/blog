# 产品需求文档 (PRD)

## 1. 项目概述

### 项目名称
戏子多秋 の 小站

### 项目愿景
打造一个具有二次元风格的、功能完善的个人博客网站，用于记录技术学习、生活感悟和动漫推荐等内容。

### 目标用户
- 技术爱好者
- 二次元文化爱好者
- 个人博客读者

### 技术栈
- **框架**: Next.js 16 + React 19
- **样式**: Tailwind CSS 4
- **动画**: Framer Motion
- **内容**: Markdown (gray-matter + remark)
- **部署**: Vercel / 自建服务器 (Next.js 动态应用)
- **版本管理**: Git

## 2. 页面结构

### 2.1 导航栏
- 固定顶部导航栏，半透明毛玻璃效果
- 导航项：首页、项目、归档、说说、友链、关于
- 当前页面高亮指示（蓝色 + 下圆点）
- 主题切换按钮（日间/夜间）

### 2.2 首页 (/)
- 搜索框（支持全文搜索）
- 个人信息卡片（头像、简介、统计、社交链接）
- 音乐播放器组件（嵌入式，不单独页面）
- 最新文章卡片
- 摄影卡片
- 开发记录卡片
- 更多文章列表
- 底部状态栏（时间、运行时长、技术栈标签）
- 浮动角色动画
- 系统状态显示

### 2.3 项目页 (/projects)
- 项目展示卡片网格
- 项目筛选（按技术/分类）
- 项目详情（链接到GitHub或演示）

### 2.4 归档页 (/archive)
- 按时间线归档的文章列表
- 按月/年分组
- 统计信息（总文章数、分类统计）

### 2.5 说说页 (/moments)
- 短内容发布/展示
- 时间线形式
- 支持文字、图片

### 2.6 友链页 (/friends)
- 友情链接展示
- 链接卡片（站点名称、描述、图标）
- 申请友链入口

### 2.7 关于页 (/about)
- 个人介绍
- 技能栈进度条
- 兴趣爱好

### 2.8 博客详情 (/blog/[slug])
- Markdown内容渲染
- 文章元信息（日期、标签、分类）
- 阅读时间估计
- 目录导航

## 4. 非功能性需求

- **响应式设计**: 桌面端 + 移动端适配
- **SEO**: 静态导出，合理元数据
- **性能**: 快速加载，优化图片
- **可维护性**: 清晰的代码结构，TypeScript类型安全
- **可扩展性**: 模块化组件设计，便于添加新功能
