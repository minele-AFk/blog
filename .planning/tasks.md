## M6.2: 日间模式全面可读性优化 ✅ (已完成)

**目标**: 全面解决日间模式下各页面文字与背景对比度问题

### 问题分析
日间模式下，全局 light-mode 样式将 `text-white` 强制覆盖为深色 `#1e293b`，但背景层（轮换图 + 黑色遮罩）未随主题变化，导致深色标题叠暗背景，对比度仅 1.05~4.01:1。

### 改动清单
- [x] 背景轮换组件主题感知 ✅
  - 日间模式：brightness(0.9) + 白色渐变遮罩（from-white/60 via-white/20 to-white/60）
  - 夜间模式：brightness(0.45) + 黑色渐变遮罩（保持不变）
- [x] 追番页标题对比度增强 ✅
  - 日间模式：bg-white/60 → bg-white/80，border-white/40 → border-white/60
- [x] 追番页分类按钮增强 ✅
  - 日间模式：bg-black/5 → bg-black/10，hover bg-black/10 → bg-black/15
- [x] AnimeCard 番剧名字始终白色 ✅
  - 移除全局 text-white 依赖，改用内联 style={{ color: '#ffffff' }}
- [x] 全局样式补充 ✅
  - 添加 .anime-card-title、.anime-card-btn 始终白色规则
- [x] 日间模式背景亮度微调 ✅
  - brightness 1.05 → 0.9（用户反馈调亮后略微降低）
- [x] 项目/归档/说说/友链页面标题可见性 ✅
  - 背景层随主题切换，标题区域对比度从 ~2:1 提升至 ~12:1
